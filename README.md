# VEXRO Connect

> Your people. Your space. Your rules.

A safety-focused, cross-platform community and messaging platform.

## Status
Sprint 1 - Foundation. Not production ready. No E2EE yet.

## Quick start
    npm install
    npm test
    npm run dev:api

Then open http://localhost:3001/health

## Layout
    apps/api/         Fastify API
    packages/shared/  Zod schemas shared by client and API
    docs/             Threat model
    .github/          CI workflows
